# SmarterBookmarks glossary

[Documentation home](README.md)

Use this glossary when a screen, setting or guide uses an unfamiliar term. Related guides explain how to use each feature. See the [function index](FEATURES.md) for locations and requirements.

| Article Mode / Open article | The extracted reading view of a web page. Extraction depends on what readable content the site provides. | [Open an article](pages/READING.md#open-the-recipe) |
