# SmarterBookmarks functions and terms

[Documentation home](README.md)

Find a function, see where it lives, and check which guide explains it. Related controls share a row so you can follow a whole operation. Use the [glossary](GLOSSARY.md) for names and alternate terms, or start with the illustrated [user guides](GUIDES.md).

This reference covers the English controls in SmarterBookmarks. Your visible tabs depend on **Settings → Behavior → Active tabs**. A section such as Tags or Sources can appear directly in navigation or under **More**. Menus also change with selection, item state, privacy settings and feature access.

App **Pro** and an AI provider's API account are separate. Pro requirements below refer to the applicable app feature access; cloud AI also needs its provider setup and available allowance.

## Ordinary search and filters

| Function | What it does and where | Requirements | Guide |
| --- | --- | --- | --- |
| Open and close ordinary search | Toolbar Search expands the search bar and filter rows for the current library area. Closing search hides them and restores the previous page context. | A searchable list; ordinary search does not require AI setup. | [Read guide](pages/SEARCH.md#search-your-library) |
| Search as you type | Enter a word to update the current list; submitting also runs the search and dismisses focus. | Ordinary keyword mode. Each list searches its own items. | [Read guide](pages/SEARCH.md#search-your-library) |
| Clear a query and recover from no results | The search bar's clear control removes typed text; Back closes search. | Current query or open search. | [Read guide](pages/SEARCH.md#search-your-library) |
| Choose AND or OR | Search chips select whether search terms and applicable tag criteria combine as all or any matches. | Ordinary search; Tags and Sources default to OR, other main library lists default to AND. | [Read guide](pages/SEARCH.md#basic-filters) |
| Favorites and Non favorites | Search chips include or exclude favorite items. | Bookmarks, Collections or Notes context; chips are hidden for Tags and Sources. | [Read guide](pages/SEARCH.md#basic-filters) |
| Pinned and Unpinned | Search chips include or exclude pinned items. | Bookmarks, Collections or Notes context; chips are hidden for Tags and Sources. | [Read guide](pages/SEARCH.md#basic-filters) |
| Filter by created date | Date offers Today, Yesterday, Last 7/30/90/365 days and Custom; multiple selected ranges are combined. | A supported searchable list; Custom uses start/end date pickers and rejects a reversed range. | [Read guide](pages/SEARCH.md#basic-filters) |
| Filter bookmark statuses | Status opens a selection sheet grouped by built-in and custom statuses; selection immediately updates results. | Bookmarks context; selectable values come from current status definitions. | [Read guide](pages/SEARCH.md#bookmarks) |
| In collection and Not in collection | Bookmark filters select membership or lack of membership. | Bookmarks context. | [Read guide](pages/SEARCH.md#bookmarks) |
| Tagged and Untagged | Search filters distinguish items with and without tag associations. | Bookmarks or Notes context. | [Read guide](pages/SEARCH.md#bookmarks) |
| Choose particular Tags | Tags opens a searchable multiple-selection sheet; chosen tags appear as removable chips in the search row. | Bookmarks, Notes or Collections search; existing active tags, with privacy filtering. This picker does not offer tag creation. | [Read guide](pages/SEARCH.md#bookmarks) |
| Type a tag or alias in a query | A term beginning with # searches bookmark/note tags; an alias matches the tag it refers to. | Bookmarks or Notes query; matching uses actual tag or alias names. | [Read guide](pages/SEARCH.md#bookmarks) |
| Dynamic and Non dynamic | Bookmark search chips select dynamic or ordinary bookmarks. | Bookmarks context. | [Read guide](pages/SEARCH.md#bookmarks) |
| Find recorded broken bookmarks | Broken restricts the Bookmarks list to recorded broken-link state. | Bookmarks context; filtering recorded health results does not require Pro. Running health checks requires Pro with Bookmark Health Monitoring access. | [Read guide](pages/SEARCH.md#bookmarks) |
| Locked and Unlocked | Collection search chips restrict results according to lock state. | Collections context; locking requires Pro, and accessing a locked collection requires authentication. | [Read guide](pages/SEARCH.md#collections) |
| Search the current collection | A named scope chip limits search to the current collection; root displays /. | Collections context; current folder's accessible content. | [Read guide](pages/SEARCH.md#collections) |
| Include subcollections | A second scope chip includes the current collection tree. | Collections context; accessible descendants; mutually exclusive with the direct collection scope. | [Read guide](pages/SEARCH.md#collections) |
| Choose Collections or Bookmarks results | Type chips limit collection-area search to folders or bookmark members. Selecting Bookmarks reveals its field chips. | Collections context. | [Read guide](pages/SEARCH.md#collections) |
| Choose Title, Url, Description or Domain | In ordinary search, field chips select which bookmark fields to match. | Bookmarks context or Bookmarks results in Collections; FTS changes these chips into query-token shortcuts. | [Read guide](pages/SEARCH.md#bookmarks) |
| Show advanced search shortcuts | Advanced search expands Exact, Exclude and Regex shortcuts. | Ordinary search; Regex shortcut is hidden while FTS is selected. | [Read guide](pages/SEARCH.md#advanced-search) |
| Exact phrase | Exact inserts paired quotation marks, placing the cursor inside; a quoted phrase is parsed as a phrase. | Search input; ordinary keyword and applicable FTS query parsing. | [Read guide](pages/SEARCH.md#advanced-search) |
| Exclude a term | Exclude inserts a minus sign for a term to omit. | Search input; combine with positive terms for useful FTS queries. | [Read guide](pages/SEARCH.md#advanced-search) |
| Regular expression | Regex inserts a delimited expression and exposes syntax shortcuts. | Ordinary keyword mode; FTS does not use this regex shortcut. | [Read guide](pages/SEARCH.md#advanced-search) |
| Insert regex operators | Shortcut chips insert .*, [], (), digit-sequence or alphanumeric expressions at the cursor. | Expanded regex controls. | [Read guide](pages/SEARCH.md#advanced-search) |
| Switch to FTS | FTS uses the local full-text index to search supported library lists. Its selection is stored in search preferences. | Enable full-text search in Settings → Search; no AI model or semantic index needed. | [Read guide](pages/SEARCH.md#full-text-search-and-content) |
| Insert FTS field tokens | Title, Url, Description and Domain chips insert field prefixes such as title: into the query instead of toggling ordinary field matching. | FTS selected and bookmark field controls visible. | [Read guide](pages/SEARCH.md#full-text-search-and-content) |
| Search indexed library text with FTS | FTS bookmark queries can match metadata and associated tags, aliases, collections and highlights; each list uses its own text index. | FTS enabled; results depend on the list and selected fields. | [Read guide](pages/SEARCH.md#full-text-search-and-content) |
| Include saved page content in search | Content search adds indexed page text to Bookmarks FTS results and can show matching snippets. | Pro, FTS selected, Settings → Search → Search page content enabled, and available saved page content. | [Read guide](pages/SEARCH.md#full-text-search-and-content) |
| Search within one bookmark's content | Bookmark menu → Notes → Search Content opens a search sheet with saved content preview and matching excerpts. | Pro with page-content search access and available saved page content. | [Read guide](pages/SEARCH.md#full-text-search-and-content) |
| Read FTS help | Settings → Search toolbar Help opens an in-app explanation of full-text search. | Search preferences screen; no search run required. | [Read guide](pages/SEARCH.md#full-text-search-and-content) |
| Switch to AI Search | AI Search selects topic-based retrieval and changes the input to submit with Enter; ordinary filter controls are hidden. | AI Search setup and a usable index for the active list. | [Read guide](pages/SEARCH.md#ai-search) |
