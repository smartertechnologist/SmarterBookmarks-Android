# SmarterBookmarks user guides

Start with one useful page, then build a library you can return to. The beginner guides use a recipe so you can follow the same example from saving through notes and reminders.

## Start here

1. [Save your first bookmark](pages/SAVE.md): save a recipe and check the result.
2. [Find something you saved](pages/FIND.md): search by title and recover from no results.
3. [Organize with collections and tags](pages/ORGANIZE.md): create **Recipes to try** and add a **weeknight** tag.

These three workflows work without sign-in, Pro, or AI setup. See [Getting Started](GETTINGSTARTED.md) for installation and general settings.

Looking for a particular control or unfamiliar name? Use the [app function index](FEATURES.md) and [glossary](GLOSSARY.md).
